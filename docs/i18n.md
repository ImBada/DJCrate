# 다국어(i18n)

앱 화면과 CLI(`djc`) 문구는 macOS 언어 설정에 따라 한국어·영어·일본어로 나온다. CLI는 `DJC_LANG=ko|en|ja`가 우선하고, JSON은 오류 `message`만 번역한다.

## 원칙

- 문구 원문(String Catalog 키)은 **한국어**다. 코드에 쓰는 문구가 곧 키이고, 영어(`en`)·일본어(`ja`) 번역은 카탈로그에 둔다.
- 목록에 없는 언어(프랑스어 등)를 쓰는 사용자에게는 **영어**가 나온다(`CFBundleDevelopmentRegion` = `en`). 영어 번역이 빠진 문구는 한국어 원문이 그대로 보이므로 **en 누락은 늘 0**이어야 한다. ja도 0으로 둔다.
- 카탈로그 원본은 한 곳에 모은다: `Sources/DJCrate/Resources/Localizable.xcstrings`(화면 문구), `InfoPlist.xcstrings`(권한 안내·저작권 줄, ko·en·ja 모두). CLI의 `Sources/djc/Resources/Localizable.xcstrings`는 같은 원본을 가리키는 상대 링크다.
- 언어 목록은 `Sources/DJCrate/Info.plist` 한 곳에 둔다. 디버그 실행 파일에는 링커가 이 파일을 넣고(`Package.swift`의 `-sectcreate`), `scripts/build-app.sh`는 앱 번들 Info.plist에 같은 값을 복사한다. 실행 파일에 언어 목록이 없으면 메인 번들 언어가 영어뿐이라 카탈로그도 늘 영어를 고른다.

## 코드에서 쓰는 법

| 쓰는 곳 | 쓰는 법 |
|---|---|
| 문자열이 필요한 곳(NSAlert·토스트·오류 이유·계산한 표시 이름·AppKit 제목) | `String(ui: "곡 \(count)개를 지웠습니다")` |
| SwiftUI 제목 인자(`Text`·`Button`·`Label`·`Toggle`·`Picker`·`Section`·`Menu`·`.help`·`.accessibilityLabel`·`Hint`·`Value`·`Window`) | `Text(.ui("재생"))`, `Button(.ui("쓰기…")) { … }`, `.help(.ui("…"))` |
| 번역하지 않는 글(곡 제목·숫자·기호·브랜드 이름 `rekordbox`·`DJCrate`·`BPM`) | `Text(verbatim: "…")`, 또는 `String` 값을 넘긴다 |

- `String(ui:)`·`.ui(…)`는 `DJCDomain`에 있다(`UIStrings`). 앱이 시작할 때 `UIStrings.bundle`을 앱 카탈로그 번들로 정한다. CLI는 `Locale.preferredLanguages`와 `DJC_LANG`으로 고른 언어의 리소스 번들·로캘을 정한다(지역 접미사 `en-US`·`ja_JP`도 받음, 빈 환경 변수는 시스템 설정, 지원하지 않는 언어는 영어). 단위 테스트는 정하지 않아 시스템 언어와 관계없이 한국어 문구로 비교할 수 있다.
- 하위 모듈(`DJCDomain`·`RekordboxKit`·`DJCStorage`·`DJCAnalysis`)의 문구 중 앱 화면에 닿는 것(쓰기 막힘 이유·편집 거절 이유·`DJCError.errorDescription`·`recoverySuggestion`·단축키 이름 등)도 `String(ui:)`로 쓴다. 키는 앱 카탈로그에 모인다. 하위 모듈이 자기 번들(`Bundle.module`)을 두지 않는 까닭은 번들이 없는 곳(PATH에 복사한 `djc`)에서 `Bundle.module`이 멈추기 때문이다. CLI를 복사할 때는 `DJCrate_djc.bundle`도 실행 파일 옆에 두며, 빠졌으면 원문으로 실행한다.
- SwiftUI에 문자열 리터럴을 그대로 주면(`Text("…")`) 메인 번들을 찾아 개발 빌드와 앱 번들이 다르게 보인다. 검사(`scripts/i18n.swift check`)가 `String(ui:)`·`.ui(…)` 밖의 지역화 문구를 막는다.
- 번역하지 않는 것: 개발자용 `djc lab …` 출력, 표준 오류 로그(`[앱 오류] …`), 앱 자가 테스트·성능 기록 출력(`Diagnostics/`, 문서가 그 한국어 줄을 grep한다), rekordbox·파일 형식에 쓰는 문자열, 파일·폴더 이름(`DJCrate 편집본`), 코멘트 규칙의 한국어 토큰.
- 같은 한국어가 뜻에 따라 번역이 달라야 하면(재생 버튼의 "재생"과 재생 횟수 칸의 "재생") 그 문구만 키를 따로 준다: `String(localized: "library.column.plays", defaultValue: "재생", bundle: UIStrings.bundle)`, SwiftUI는 `LocalizedStringResource("…", defaultValue: "…", bundle: UIStrings.bundle)`. 키는 `영역.뜻` 영어 점 표기로 짓는다. 검사는 이 형태를 `bundle: UIStrings.bundle`이 있을 때만 받는다.
- 문장 조각을 `+`로 잇지 않는다. 어순이 언어마다 달라서 문장 하나를 키 하나로 두고 값을 보간한다(`"\(name)을 지웠습니다"`). 보간 값이 둘 이상이면 번역에서 순서를 바꿀 수 있게 `%1$@`·`%2$@`처럼 위치를 적는다.
- 보간 타입이 키의 자리표시자를 정한다: 문자열 `%@`, 정수 `%lld`, `Double` `%lf`. `Double`을 그냥 넣으면 소수 여섯 자리가 나오므로 `\(bpm, format: .number.precision(.fractionLength(2)))`처럼 형식을 주거나 `specifier: "%.1f"`를 준다. 번역 값의 글자 `%`는 `%%`로 쓴다.
- 영어에서 수에 따라 달라지는 말은 카탈로그의 복수형 변형(`one`·`other`)으로 둔다. 일본어·한국어는 변형 없이 하나.
- 수·날짜는 로캘 형식으로: 화면의 소수(BPM·dB·LUFS)는 `.formatted(.number.precision(.fractionLength(n)).grouping(.never))`나 `specifier:`(로캘 소수점을 따름), 날짜·시각은 `.formatted(date:time:)`. 재생 위치 시계(`m:ss.mmm`)는 DJ 기기와 같은 고정 표기로, 입력 칸 값(BPM 입력)은 파싱과 짝이라 그대로, rekordbox XML·DB·파일 이름에 쓰는 수는 늘 `String(format:)`(POSIX)로 둔다.

## 도구

```bash
swift scripts/i18n.swift sync    # 빌드 → 코드에서 뽑은 문구로 카탈로그 고치기(새 문구 더하기, 안 쓰는 문구 빼기·옛 번역 출력). 고정 서식으로 저장
swift scripts/i18n.swift check   # scripts/check.sh가 부른다: 카탈로그 = 코드, en·ja 누락 0, 자리표시자 일치, .ui 밖 문구 0, 고정 서식
swift scripts/i18n.swift format  # 빌드 없이 카탈로그를 고정 서식으로만 다시 쓰기(JSON을 손으로 고친 뒤)
```

- 문구는 컴파일러가 타입을 보고 뽑는다(`.stringsdata`, `Package.swift`의 `defaultLocalization`이 있으면 모든 타깃에서 나온다). 스크립트는 디버그 빌드 결과에서 앱·CLI·하위 모듈 소스의 것을 쓴다.
- 새 문구를 더하면: 코드 작성 → `sync` → 카탈로그에 en·ja 번역 채우기(Xcode에서 `.xcstrings`를 열거나 JSON을 직접 고침, `state`는 `translated`) → `check`.
- 카탈로그는 늘 고정 서식(들여쓰기 2칸, `"키" : 값`, 모든 객체의 키를 UTF-8 바이트 순서로, `/`는 이스케이프하지 않음, 빈 객체는 줄바꿈 둘, 끝 줄바꿈 하나)이다. `sync`·`format`이 이 서식으로 저장하므로 바뀐 문구가 없으면 파일이 바이트까지 그대로다. 손으로 고쳐 서식이 어긋나면 `check`가 알리니 `format`을 돌린다.
- 문구를 고치면 키가 바뀌어 옛 번역이 빠진다. `sync`가 뺀 문구의 옛 번역을 출력하니 새 키에 옮겨 고친다.

## 문체

- 영어: 메뉴·버튼은 Title Case("Write to rekordbox…"), 설명·안내 문장은 문장형. 대화상자를 여는 항목은 "…"로 끝낸다(원문과 같게). "Please"는 쓰지 않는다. 막힘·오류 이유는 원문처럼 무엇을 하면 되는지까지 한 문장으로.
- 일본어: 문장은 です・ます체, 버튼·메뉴는 짧은 명사·동사형(「書き込む」「削除」). 일본어와 라틴 문자 사이에 빈칸을 두지 않는다(`rekordboxに書き込む`). 문장 부호는 전각(、。「」（）), 말줄임은 원문과 같게 "…".
- 공통: rekordbox 표기는 rekordbox 해당 언어판과 같게(아래 표). `rekordbox`는 늘 소문자, `DJCrate`·`BPM`·`USB`·`XML`은 그대로.
